## Installation

Clone the repository

Install needed libraries to python 3.14+ with pip:

```text
pip install -r requirements.txt
```

## Usage

Run breezyPlot.py using python with needed libraries installed and a browser should open up where you can input CSV/XLS/XLSX data files. Select required options and the plot will be created.
